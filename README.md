# Finance Quiz Pack

This package includes multiple formats to use in teaching finance English.

Files:
- finance_lesson_pack.json — original question pack
- finance_lesson_pack.csv — spreadsheet version (question,answer,example,topic,difficulty)
- finance_lesson_pack_preview.pdf — 3-question student preview
- finance_lesson_pack_answers.pdf — answers for preview
- finance_lesson_pack_answers.txt — plain-text answers
- finance_worksheet.pdf — printable worksheet (if present)
- LICENSE.txt — suggested license

How to use:
- Unzip the package.
- Open the CSV in Excel/Google Sheets for editing.
- Print the preview or worksheet PDFs for classroom use.
- Import the JSON/CSV into your LMS or use the CSV to create Google Forms.
